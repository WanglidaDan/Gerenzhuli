# 个人助理（Gerenzhuli）

只为用户一个人服务的 iOS 生活管家 App。iOS 17+，SwiftUI + SwiftData。

## 五个页签

- **今日**：问候语、三格数字（日程 / 提醒 / 已过期）、深墨绿早报大卡、「接下来」日程、「提醒」标题列表（未完成、按日期升序、最近 5 条，点进提醒页）、「待处理」（点一行在首页原地展开，不跳页）、订阅卡（月收入由订阅行实时加总及三平台拆分）。
- **日历**：日 / 周视图切换，点日期看当天日程。
- **提醒**：竖向时间线，顶部深色「结论」卡自动汇总最先要做的两件；左侧节点 + 竖线串联，状态分已完成 / 已逾期 / 进行中 / 接下来四种；点节点勾选完成，新建提醒照样进时间线。
- **订阅**：流媒体订阅 15 位台账种子，月收入由订阅行实时加总；按 Netflix / HBO Max / Disney+ 筛选；k（Disney+）已过期置顶。
- **出行**：记行程——出发、交通、住宿、要去的地方按时间排；机票 / 门票 / 订单挂在行程下面。导航走 MapKit（打开苹果地图），票证进钱包是占位（待接 PassKit），行程配图走 Photos（PHPicker），订票是查价比价 + 下单确认流程占位（不写死支付、不扣款）。

另有：首次打开权限页（提醒事项、日历、麦克风、语音识别四项分开申请，数据只留在本机）、语音输入（右下角悬浮麦克风：Speech 转写 → 大模型解析 → 确认卡 → 确认后写入）、早报详情页（按定版格式：国内 / 国际 / 财经 / 科技四节，内容一律「待生成」占位，不编造新闻）、设置页（大模型 API Key 填钥匙串）。

## 视觉

网页原型（artifact `ge-ren-zhu-li`）为视觉真值：系统字体 SF Pro，大标题 25、正文 12.5–14pt；分组列表质感（0.5px 发丝线、圆角 12–14、柔和阴影）；底部毛玻璃标签栏；深浅色模式（深色纯黑底 + #1C1C1E）。

## 种子数据与真实数据

首次打开时 `Store.seedIfNeeded` 写入演示种子（提醒、日程、15 位订阅、两条出行示例、12 项早报占位）。上线前按 `Models.swift` / `Store.swift` 里的 TODO 替换为真实数据源：提醒 + 日历接 EventKit，订阅接 Notion 台账 / 取码系统，早报接每日 08:10 的早报任务，订票查价接真实票务接口，出行地点用地名反编码存经纬度。

## 打开与编译

```bash
open Gerenzhuli.xcodeproj
```

需要 Xcode 16+、iOS 17+ 真机或模拟器。增删 Swift 文件后重新运行 `python3 tools/gen_pbxproj.py` 再编译。

App 图标目前是深墨绿渐变占位图（`Assets.xcassets/AppIcon.appiconset/Icon-1024.png`），上架前换成正式图标。

## 权限（Info.plist）

提醒事项、日历（完整访问）、麦克风、语音识别、定位（使用期间，用于出行导航）。**没有通讯录权限**——通讯录页已拿掉，换成出行。
